# Calendar Vault 📅

A lightweight, fully offline calendar web app with built-in Philippine holidays, search/filtering, and local storage support.

## ✨ Features

* **Offline First:** Runs directly in your browser with zero installation or server required.
* **PH Holidays Built-in:** Includes 2026 Philippine holidays with quick search and filter options.
* **Events & Reminders:** Add, track, and manage custom events, deadlines, and keepsakes.
* **File Attachments:** Attach small files directly to calendar entries.
* **Local Data Persistence:** All entries automatically save to your browser's local storage.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `index.html` in any browser.
3. Start adding your entries!
